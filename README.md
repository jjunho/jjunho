# Juliano Paiva Junho

Language technology and developer tooling. Most projects sit where Portuguese, Korean and software meet.

### Language tools
- [`silabificacao`](https://github.com/jjunho/silabificacao) — Portuguese syllabification: Haskell API + Elm UI
- [`my_dictionary`](https://github.com/jjunho/my_dictionary) — linguistic dictionary, Elm frontend and Haskell backend
- [`numerais`](https://github.com/jjunho/numerais) — integers to Portuguese numerals (BR and EU)
- [`viet_dict`](https://github.com/jjunho/viet_dict) — Chữ Nôm dictionary search
- [`questoes-elm`](https://github.com/jjunho/questoes-elm) — exercise types for language teaching
- [`trad`](https://github.com/jjunho/trad) — Korean → Portuguese translation workflow

### Ternary computing
- [`CPU3`](https://github.com/jjunho/CPU3) — balanced ternary CPU with assembler and debugger
- [`Z80T`](https://github.com/jjunho/Z80T) — balanced ternary extension of the Z80
- [`x`](https://github.com/jjunho/x) — TBX, a ternary binary exchange format in Rust

### Editors and agent tooling
- [`hwp_vscode`](https://github.com/jjunho/hwp_vscode) — HWP/HWPX viewer for VS Code
- [`count-words`](https://github.com/jjunho/count-words) — live word and character counts in the status bar
- [`dsh-chatgpt-oauth`](https://github.com/jjunho/dsh-chatgpt-oauth) — ChatGPT OAuth (PKCE) for DeepSeek Harness
- [`pocketelm`](https://github.com/jjunho/pocketelm) — Elm/Acadia backend workbench

### Systems
- [`visual-studio-code-autoupdate`](https://github.com/jjunho/visual-studio-code-autoupdate) — VS Code updater for Arch Linux
- [`960qgk-acpi-fan-fix`](https://github.com/jjunho/960qgk-acpi-fan-fix) — ACPI fix for Galaxy Book 960QGK fan control

Main languages: Haskell, Elm, TypeScript, Python, Rust.
